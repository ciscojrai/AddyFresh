# Contributing to FreshAddy

Thank you for your interest in contributing to FreshAddy!

## Development Workflow

1. Fork the repository and create your branch from `main`.
2. Run `npm install` to install dependencies.
3. Start the dev server with `npm run dev`.
4. Ensure your code passes TypeScript checks with `npm run lint`.
5. Run the production build test with `npm run build`.

## Submitting Pull Requests

- Keep PRs focused on a single feature or bug fix.
- Follow the existing code style and formatting.
- Provide a clear description of changes in your pull request.
